## Contract și decizii

- `POST /api/v1/engagements` prin cookie, Origin și CSRF local scrie o revizie 1 în PostgreSQL, apoi o recitește după commit. `GET /{id}` și lista keyset (`limit` 1–50, `after` UUID) sunt autentificate; lista returnează rezumate, nu payloadul integral al tuturor drafturilor. Autorizația/scope-ul sunt **declarații**, nu granturi către executori. Fără catalog, `workflow_profile_ref` este numai `null`; `operation_refs` trebuie să fie goale. Această restricție evită referințe străine nerezolvabile, nu simulează catalogul.
- Schema `0007_engagement_drafts` păstrează un head per engagement prin FK compus deferat, revizii cu FK/unique/check și trigger de imutabilitate. Digestul este SHA-256 peste UTF-8 CanonicalJSON cu chei sortate, separatori compacți și `ensure_ascii=false` pentru `{schema_version,kind,id,revision,payload}`, fără propriul digest. Scopul, obiectivul, constrângerile și fereastra autorizării sunt payload versionat strict; identificatorii și revizia sunt coloane. Nu se creează RunSnapshot/MissionSpec.
- HTTP păstrează Host/Origin/session/CSRF P0; numai `POST /api/v1/engagements` primește plafon de corp **1 MiB wire**. Payloadul canonic al draftului are plafon agregat **1.000.000 bytes** declarat în schema OpenAPI: o depășire sub limita wire dă 422 `body/TOO_LONG`, peste limita wire dă 413; formele admise cu maximul obiectivului și context mare au readback real. Numai lista GET permite query `limit`/`after` fără duplicate. Pairing rămâne la 4096 bytes și fără query. Erorile 422 au câmpuri/coduri allowlisted, fără valori introduse ori traceback; OpenAPI și TS se regenerează din sursă. P0 clientul nu afișează încă aceste erori per câmp; consumatorul vizual este B04.
- Nu există auto-upgrade la `omnis start`. Probează numai DB-uri disposable atestate, inclusiv upgrade cu sesiuni P0 păstrate din 0006. **Nu migra PGDATA operatorului fără backup/restaurare verificată și o cale de release explicită**: vechiul release refuză noua schemă; installerul actual nu înlocuiește un release cu aceiași bytes de versiune pe un data home existent. Aceasta nu este o instalare peste profilul P0 al operatorului.
