**Adjudecare „restart”, înainte de cod.** Planul SL04/D02 spune „comenzi stop/status/restart instalate”; arhitectura §4.1 enumeră `stop`, `status`, `omnis` și `start --no-open`, **nu** un subcomandă `restart`, iar §4.2 pasul 5 și §4.3 cer pornire explicită nouă după stop complet. În această felie „restart” este *acțiunea* operatorului `omnis stop` → `omnis start --no-open` (ori `omnis` interactiv) → `omnis status`, nu o nouă comandă implicită care ar putea relua lucrul. Aceasta satisface comportamentul restart explicit al arhitecturii și ieșirea observabilă a planului; dacă rândul planului este interpretat literal ca nume obligatoriu de subcomandă `omnis restart`, acel detaliu rămâne **BLOCKED pentru decizie de contract** și nu se inventează din test. `omnis run stop` rămâne nelivrat: nu este sinonim cu stopul instanței.

**Output/exit propus:** `stop` nu emite coduri de pairing/secrete; JSON opțional numai dacă implementarea îl poate valida integral. Textul și JSON status rămân sanitizate, cu `dashboard_ready=false`, `assessment_ready=false` după stop; `STOPPING` este intenția închisă fără dovadă completă, `STOPPED` necesită dovada quiescenței DB **și** readbackul exact al resurselor proprii, `RECOVERY_REQUIRED`/`UNCERTAIN` înseamnă identitate/efect/deadline necunoscut. Exit 0 doar după readback complet (inclusiv stop idempotent); 2 precondiție/config/identitate neautorizată înainte de efect; 3 indisponibilitate sigură fără stop confirmat; 4 efect sau recovery incert, inclusiv ACK pierdut, marker nereconciliat sau cleanup parțial. Nici FINALIZE, nici reply IPC succes, nici o stare locală singură nu certifică STOPPED. Startul nou redeschide exclusiv sub lock local + tranzacție DB, la generație/epoch nou și identitate/readback complet; nu face autoresume sau migrare de upgrade. Când DB/controlul nu este accesibil, markerul privat `unreconciled` trebuie persistat/citit înainte de teardown atestat; dacă persistența e imposibilă, verdict 4 și Start refuzat până la reconciliere externă, chiar dacă se încearcă eliminarea căilor proprii de efect.
