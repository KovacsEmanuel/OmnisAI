## Remedieri după review independent

Review-ul a găsit trei P1 și două P2, toate în perimetrul instalării. Exportul fals `-r ../../outside.txt` cu `--hash=sha256:` într-un comentariu a trecut builderul inițial (**RED: exit 0 în loc de 2**); acum bytes întregi sunt comparați cu exportul `uv --locked` al API-ului din checkout, rulat cu argv fix și mediu redus, iar proba refuză fișierul fals. Calea `OMNIS_UV` este inputul trusted al operatorului; pe lângă calea canonică, builderul verifică versiunea `uv 0.12.19` înainte de export. Un UV sintetic care declara altă versiune, dar emitea aceiași bytes, a trecut RED și este acum refuzat; versiunea declarată nu este o dovadă criptografică a binarului. Un `$XDG_DATA_HOME` lipsă eșua înainte de copiere (**RED: ReleaseError**); acum se validează ancestorul existent înainte de crearea directorului privat 0700, iar testul cu wheel instalat pornește dintr-un XDG data home inexistent. Suprapunerea bundle/data-home era acceptată (**RED: fără ReleaseError**); este refuzată înaintea primei scrieri.

Publicarea directoarelor folosește `renameat2(RENAME_NOREPLACE)` pe Linux, verificată cu o destinație goală concurentă (**RED: importul helperului lipsă, GREEN: FileExistsError fără suprascriere**). Installerul serializează scrierile sale cu `install.lock` privat; pointerul `installed.json` este publicat prin hardlink no-replace, cu readback al câștigătorului. O injecție de pointer diferit chiar înainte de publicare înlocuia anterior fișierul concurent (**RED: nu a aruncat eroare**); acum nu îl șterge și raportează conflict. Re-review-ul independent a confirmat acele cinci remedieri, dar a găsit un nou P2: `FileExistsError` urmat de dispariția pointerului putea întoarce succes fără receipt. Injecția acelei intercalări a eșuat RED; acum absența la readback refuză instalarea, inclusiv după publicarea proprie. Crash între publicarea directorului și a pointerului poate lăsa un release al cărui conținut este readback-verificat la următoarea instalare; nu se șterg date ori volume pentru „reparare”. Testele nu certifică adversari same-UID sau filesystemuri fără primitive Linux suportate.

Scratch-ul de test este disposable și este eliminat de fixture după readback; nu s-au atins releaseuri din home-ul operatorului. Rollback cod: inspecția commitului/dependențelor → `git revert <sha>` → reconstruirea bundleului și gate-ul. Git nu dezinstalează un release extern; îndepărtarea lui necesită identificare exactă/backup dacă există date și nu face parte din `omnis stop`.
