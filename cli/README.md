# CLI P0.4 — primul increment: status privat instalat

`omnis-cli==0.1.0` este un wheel separat, fără dependențe API/Hermes. În această felie, singura comandă este `omnis status [--json]`: citește un `instance.json` privat și interoghează `control.sock` cu peer UID + capability din directorul privat. Nu citește `.env`, nu caută checkoutul, nu contactează provider/ținte și nu pornește servicii. `control_ready=true` nu certifică HTTP/assets: `dashboard_ready=false`, `reason=HTTP_UNVERIFIED` chiar dacă supervisorul răspunde. `NOT_INSTALLED`/`CONTROL_UNAVAILABLE` nu adoptă un port străin și nu modifică fișiere. Coduri exit: 0 control verificat, 2 metadata invalidă, 3 absent/indisponibil.

Contractul provizoriu al metadata este `$XDG_STATE_HOME/omnis/instance.json` (implicit `~/.local/state/omnis`), 0600, director 0700, câmpuri `version=1`, `instance_id`, `release`, `schema`, `project`, `origin`. IPC este în `$XDG_RUNTIME_DIR/omnis`, sau în `runtime-ipc/` sub state dacă lipsește XDG runtime. Metadata și directoarele trebuie să fie private/canonice; o instanță reală va fi instalată de felia următoare, nu prin copierea unui `.env`. Nu considerați `instance.json` sursă de autoritate pentru starea DB.

Pregătire explicită din repo, cu uv 0.12.19 / Python 3.13.15: `uv sync --locked --no-config --no-python-downloads --python 3.13.15 --directory cli`; `make check-cli UV=/cale/uv-0.12.19`. Acesta verifică testele, lockul, format/lint și wheelul instalat într-un mediu scratch, rulat din afara checkoutului. Instalarea într-o locație de utilizator este o operație explicită: `uv build --no-config --wheel cli --out-dir <scratch>` și `uv pip install --python <venv-cli>/bin/python --no-deps <scratch>/omnis_cli-0.1.0-py3-none-any.whl`. `omnis status --json` dintr-un director extern, fără instanță, raportează `NOT_INSTALLED` și exit 3; nu înseamnă G00/P0.4 complet.

**Nu sunt încă livrate:** manifestul releaseului, instalarea control plane-ului, statusul HTTP legat de identity, startupul/lockul containerelor, pairing, browser/open, stop/receipt, topologia/UID și probele L01–L05/L08 complete. Nu instalați acest wheel ca serviciu operațional până la acele felii. Rollback cod: inspectați commitul și faceți `git revert`; wheelul deja instalat, procesele și datele din afara repo-ului cer operații explicite separate.
