# OmnisAI

Platformă web locală propusă pentru evaluări Web/API autorizate, cu runtime și agenți Hermes.

**Stare:** documentare și planificare. Direcția de produs și folosirea skill-urilor native au fost acceptate în discuție; stackul și etapele concrete sunt propuse în plan. Aplicația nu este încă implementată.
