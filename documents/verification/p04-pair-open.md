## Execuție și adjudecare

### Implementare și limite ale contractului

- `pair` verifică TTY pe stdin **și** stdout înainte de generare sau IPC; `--json` refuză înainte de emitere. Digestul SHA-256 și UUID-ul issuance merg prin `control.sock`; niciun cod în argv, URL, JSON sau jurnalul CLI. `SessionStore` păstrează TTL-ul DB de 5 minute, înregistrarea atomică/consumul unic și session/logout. După review, emiterea a fost mutată sub același lock/tranzacție `InstanceControl` ca shutdownul: lease-ul, instance ID și admiterea sunt reverificate înainte de înregistrare; două store-uri sau endpointuri noi nu au fost adăugate. Răspunsul IPC cere acum câmpurile exacte, inclusiv `shutdown_command_id`.
- Eroare înaintea afișării: diagnostic fix/sanitizat; scriere TTY parțială sau flush eșuat după înregistrare: `PAIRING_DISPLAY_UNCERTAIN`/exit 4, **nu** afirmația falsă că secretul n-a fost văzut și nici retry automat. Un cod deja emis, dar nedivulgat, expiră pe server și poate fi invalidat prin emitere nouă explicită.
- `open` citește și validează manifest/image receipt, jurnalul READY, container IDs/mounts/daemon/DB/schema/lease/IPC/peer/listener, HTTP și bytes asset sub lockurile SL02; numai originul receiptului atestat, fără start/rebind/config/cwd. `omnis` implicit folosește startupul SL02, emite codul inițial numai în TTY pe instanță nouă prin același issuer, verifică din nou identitatea/originul și încearcă openerul. `xdg-open` prin argv list/mediu minim: `BROWSER_UNAVAILABLE` exit 2, `BROWSER_LAUNCH_FAILED` exit 3, `BROWSER_LAUNCH_ACCEPTED` exit 0. Ultimul certifică doar acceptarea cererii de OS, **nu** o fereastră deschisă sau sesiune paired; `browser_opened=true` nu este revendicat. Startup/readiness eșuat nu apelează openerul.
- M22/config.toml și porturile configurate din fișier rămân viitoare; defaultul implicit este 8765, `start --port` selectează numai o instanță nouă. Proba `omnis` nouă folosește 8765 numai dacă bindul e liber; nu maschează conflictul prin port arbitrar. Fără `stop` operațional/recovery, runtime Hermes, provider, țintă sau assessment.
